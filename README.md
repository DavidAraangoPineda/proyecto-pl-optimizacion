# Aplicación de Programación Lineal

Proyecto de Optimización — Universidad de Antioquia, Facultad de Ingeniería, Departamento de Ingeniería de Sistemas.

**Integrantes:** David Arango Pineda · Juan Ignacio Parra

## Descripción

Aplicación con interfaz gráfica que resuelve problemas de programación lineal con un método propio (Gran M y/o simplex revisado), mostrando el proceso completo:

- Entrada de problemas generales (Max/Min, n variables, m restricciones con ≤, ≥, =, lados derechos de cualquier signo) con validación.
- Modo solución directa o paso a paso (forma estándar, variable entrante, razón mínima, saliente, pivote, tablero).
- Solución óptima: variables, Z, holguras/excesos.
- Método gráfico para 2 variables.
- Análisis de sensibilidad (precios sombra, costos reducidos, rangos de coeficientes y lados derechos).
- Casos especiales: infactible, no acotado, óptimos múltiples, degenerado.

> Las librerías de optimización (scipy, PuLP, OR-Tools) se usan únicamente para verificar resultados, nunca para producirlos.
